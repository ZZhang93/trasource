# Security Policy

## Supported Versions

Security fixes are provided for the latest released version. Users should
upgrade to the newest release before reporting an issue that may already have
been corrected.

## Reporting a Vulnerability

Please do not disclose an unpatched vulnerability in a public issue. Use the
repository's **Security** tab to submit a private GitHub Security Advisory with:

- affected version and operating system;
- reproduction steps or a minimal proof of concept;
- likely impact and the data or files involved; and
- any suggested mitigation.

Do not include real API keys, private documents, or user databases. If private
advisories are unavailable, open a public issue containing no exploit details
and ask the maintainer for a private contact channel.

You should receive an acknowledgement within seven days. Release timing depends
on severity and whether a data migration or desktop signing update is required.
